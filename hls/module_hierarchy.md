# HLS-generated module hierarchy

This document lists, for each case study, the Verilog modules that Vitis HLS 2024.2 generated (folder `hls/`), their roles, and how they are instantiated. It complements Section 4.1 of the paper, which uses short descriptive names for the submodules.

**Naming convention.** Vitis HLS prefixes the name of every generated submodule with the name of the top-level function (e.g., `factorial_` + `flow_control_loop_pipe_sequential_init`). Each module lives in a file with the same name (`<module>.v`) inside the folder of its algorithm. The `*_tb.v` files are the manually written HDL testbenches used in Phase 3 (they are not generated by Vitis).

**Terms used in the paper.**

| Term in the paper | Meaning |
|---|---|
| Top-level module | Module that holds the FSM (control unit) and the block-level interface (`ap_*` signals) |
| Loop pipeline module | Module generated for the loop body (`..._Pipeline_<LOOP_NAME>`) |
| Multiplier | Multiplier module (`..._mul_<widths>_<latency>_1`) |
| Loop-control module | Standard module `..._flow_control_loop_pipe_sequential_init`, which manages the start and end signals of the loop |

## Summary

| Algorithm (folder) | Top-level module | Loop pipeline module(s) | Multiplier module(s) | Loop-control module |
|---|---|---|---|---|
| Arithmetic Progression Sum (`hls/arith-prog-sum/`) | `arith_prog_sum` | none (closed form, no loop) | `arith_prog_sum_mul_32ns_32ns_33_2_1` (1 instance), `arith_prog_sum_mul_32s_32s_32_2_1` (2 instances) | none |
| Factorial (`hls/factorial/`) | `factorial` | `factorial_factorial_Pipeline_FOR_LOOP_STATEMENT` | `factorial_mul_16s_16s_16_1_1` | `factorial_flow_control_loop_pipe_sequential_init` |
| Integer Square Root (`hls/sqrt/`) | `sqrt_hls` | `sqrt_hls_sqrt_hls_Pipeline_WHILE_LOOP` | none | `sqrt_hls_flow_control_loop_pipe_sequential_init` |
| Factorial-SQRT (`hls/factorial_sqrt/`) | `factorial_sqrt` | `factorial_sqrt_factorial_sqrt_Pipeline_FOR_LOOP` (factorial), `factorial_sqrt_factorial_sqrt_Pipeline_VITIS_LOOP_26_1` (square root) | `factorial_sqrt_mul_32s_32s_32_2_1` (1 instance) | `factorial_sqrt_flow_control_loop_pipe_sequential_init` (1 instance per loop pipeline, 2 in total) |

## Hierarchy per algorithm

Instance names, as they appear in the Verilog, are shown in parentheses.

### Arithmetic Progression Sum

```
arith_prog_sum                                  (top-level, FSM with six states)
├── arith_prog_sum_mul_32ns_32ns_33_2_1         (mul_32ns_32ns_33_2_1_U1)  unsigned 32x32 -> 33 bits
├── arith_prog_sum_mul_32s_32s_32_2_1           (mul_32s_32s_32_2_1_U2)    signed 32x32 -> 32 bits
└── arith_prog_sum_mul_32s_32s_32_2_1           (mul_32s_32s_32_2_1_U3)    signed 32x32 -> 32 bits
```

Two multiplier module types, instantiated three times in total.

### Factorial

```
factorial                                                   (top-level, FSM with three states)
└── factorial_factorial_Pipeline_FOR_LOOP_STATEMENT         (grp_factorial_Pipeline_FOR_LOOP_STATEMENT_fu_49)
    ├── factorial_mul_16s_16s_16_1_1                        (mul_16s_16s_16_1_1_U1)
    └── factorial_flow_control_loop_pipe_sequential_init    (flow_control_loop_pipe_sequential_init_U)
```

### Integer Square Root

```
sqrt_hls                                                    (top-level, FSM with three states)
└── sqrt_hls_sqrt_hls_Pipeline_WHILE_LOOP                   (grp_sqrt_hls_Pipeline_WHILE_LOOP_fu_51)
    └── sqrt_hls_flow_control_loop_pipe_sequential_init     (flow_control_loop_pipe_sequential_init_U)
```

No multiplier is generated.

### Factorial-SQRT

```
factorial_sqrt                                                          (top-level, FSM with five states)
├── factorial_sqrt_factorial_sqrt_Pipeline_FOR_LOOP                     (grp_factorial_sqrt_Pipeline_FOR_LOOP_fu_57)
│   ├── factorial_sqrt_mul_32s_32s_32_2_1                               (mul_32s_32s_32_2_1_U1)
│   └── factorial_sqrt_flow_control_loop_pipe_sequential_init           (flow_control_loop_pipe_sequential_init_U)
└── factorial_sqrt_factorial_sqrt_Pipeline_VITIS_LOOP_26_1              (grp_factorial_sqrt_Pipeline_VITIS_LOOP_26_1_fu_64)
    └── factorial_sqrt_flow_control_loop_pipe_sequential_init           (flow_control_loop_pipe_sequential_init_U)
```

The multiplier is used only by the factorial loop. Each loop pipeline instantiates its own copy of the loop-control module.
